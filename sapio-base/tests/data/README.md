The CTV hash vectors are an unmodified subset of the official BIP-119
vectors, retrieved on 2026-09-07:

https://github.com/bitcoin/bips/blob/master/bip-0119/vectors/ctvhash.json

The smallest transaction in each combination of witness presence and
nonempty scriptSig presence is included, with all supplied input indices
and expected hashes. Expected values come from the reference implementation.
