# Staged vault

Wraps the library vault with address or tree cold-storage destinations. Timelocks, step counts, payouts and tree limits are validated by the library.

See the [workspace guide](../README.md) for Cargo build and test commands,
funding assumptions, and the complete executable catalog. This module has a
[representative input](../../contrib/vectors/examples/vault.json).

Coverage: Catalog plus library vault tests.
