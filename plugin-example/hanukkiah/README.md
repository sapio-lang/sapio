# Scheduled candles

Builds eight timed transactions paying 36 candles. Its recipient field is one whitespace-separated string containing 36 addresses.

See the [workspace guide](../README.md) for Cargo build and test commands,
funding assumptions, and the complete executable catalog. This module has a
[representative input](../../contrib/vectors/examples/hanukkiah.json).

Coverage: Catalog plus library schedule and recipient tests.
