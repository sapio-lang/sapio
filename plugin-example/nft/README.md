# Metadata NFT

Commits metadata and lets the owner propose a sale through a selected module. Metadata requires version zero and a valid one-based edition. Artist blessings are committed metadata, not verified provenance.

See the [workspace guide](../README.md) for Cargo build and test commands,
funding assumptions, and the complete executable catalog. This module has a
[representative input](../../contrib/vectors/examples/nft.json).

Coverage: Catalog compiles the real minting guest.
